pytest hooks for the pySIMsalabim tests.

Before the session, the test input files (sim_inputs/default) are brought to the SIMsalabim version and copied into SIMsalabim/SimSS and SIMsalabim/ZimT; after the session they are removed. See sim_inputs_setup.py for details.

pySIMsalabim.tests.sim_inputs_setup module

Prepare the SIMsalabim input files used by the pySIMsalabim tests.

The tests use their own input files, stored in sim_inputs/default/{SimSS,ZimT} and named *_test.txt so that they never overwrite the user’s own files in the SIMsalabim folder.

prepare_test_inputs():

  1. compares the version of every simulation_setup*.txt in sim_inputs (and of the layer files it references) with the SIMsalabim version (version = 'X.YY' in simss.pas / zimt.pas);

  2. on a mismatch, compiles SIMsalabim’s Updater (Tools/Updater/Updater.pas) if needed, places a temporary copy next to the input files and runs it interactively (the user answers its questions), converting them in place in sim_inputs (the converted files show up in git status and can be committed as the new baseline);

  3. copies the input files into SIMsalabim/SimSS and SIMsalabim/ZimT, where the tests run.

cleanup_test_inputs() deletes the copied files again, plus the Block.txt created by the contactless-device tests (trPL) if it did not exist before.

Both are called by conftest.py (pytest session start/finish), by the __main__ block of each test file when it is run directly, and by the example notebooks in Notebooks/. The notebooks call prepare_test_inputs(convert=False): a Jupyter kernel cannot give the interactive Updater a terminal, so on a version mismatch they stop and ask the user to convert the files from a terminal with

python pySIMsalabim/tests/sim_inputs_setup.py

which only checks/converts the files in sim_inputs (nothing is copied).

pySIMsalabim.tests.sim_inputs_setup.prepare_test_inputs(log=<built-in function print>, terminal_access=<class 'contextlib.nullcontext'>, convert=True)[source]

Bring the test input files to the SIMsalabim version and copy them into SIMsalabim/SimSS and ZimT. log is called with each progress message (print by default; conftest.py passes pytest’s terminal writer). terminal_access is a context manager giving the interactive Updater access to the terminal. With convert=False (used by the notebooks) a version mismatch raises TestInputsError instead of running the Updater. All versions are checked before anything is copied.

pySIMsalabim.tests.sim_inputs_setup.run_updater(updater_binary, input_dir, setup_name, terminal_access=<class 'contextlib.nullcontext'>)[source]

Run a temporary copy of the Updater in input_dir to convert setup_name and its layer files in place.

The Updater runs interactively in the user’s terminal: its output is shown and the user answers its questions (overwrite confirmation, warnings) themselves. terminal_access is a context manager that gives the subprocess the real terminal (conftest.py uses it to suspend pytest’s capturing). Returns the Updater’s exit code.
